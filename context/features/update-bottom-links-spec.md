# Update Bottom Links

## Overview

Update the bottom links that are visible in the footer.

## Requirements

- In the Forum Settings -> Bottom Links section display all the bottom links in cards (one link configuration per card)
- All cards need to contain a form that have two fields: Link text and Link. Link text is the text of the link and link is the link
- Show a fa-times icon on the right of each cards. Clicking on the icon deletes the link
- On tablet and desktop make the cards take 50% of the available width while on lower resolutions make the cards take the full width
- Do not display two cards side by side on tablet and desktop
- Have a "Add Link" button at the bottom left under the cards to add a new link
- Under the "Add Link" button add a button called "Save" to save the links configuration. On click save the links configuration and update the bottom links saved in the application.
- Use the same design that is used for the forum settings
