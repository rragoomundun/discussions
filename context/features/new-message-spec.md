# New Message

## Overview

Message input component.

## Requirements

- Create a new shared component called MessageInput
- It has to show a text-input of at least 8 rows with the placeholder "Write your message here."
- It has to show under the text input two buttons: "Preview" and "Reply"
- On "Preview" click show a modal with the previewed message. Use utilService.markdownToHTML to format the message
- On "Reply" click emit the message
